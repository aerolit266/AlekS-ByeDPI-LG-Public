# AlekS ByeDPI для LG webOS — Public 0.6.32

**Русский** · [English](README_EN.md)

AlekS ByeDPI — приложение для LG webOS с root и Homebrew Channel. Локальный DNS/SNI-мост и нативная обработка TCP-трафика помогают официальному приложению YouTube подключаться в сетях с DPI-фильтрацией. **Это не VPN и не гарантия обхода всех блокировок.**

## Возможности

- Единый IPK с нативными компонентами ARMv7 и ARM64 и интерфейсом для пульта.
- Автоматический выбор LAN-интерфейса и частного IPv4 (192.168.x.x, 10.x.x.x, 172.16–31.x.x) без привязки к конкретному телевизору.
- Раздельные локальные маршруты для запросов и видеоданных: SOCKS 10881 и 10882.
- **R296:** DNS привязывается к окружению официального YouTube Cobalt после запуска и проверки процесса.
- Проверка состояния собственных компонентов, ручное включение/отключение и восстановление изменённых настроек при остановке.
- **Нет встроенных адресов частных VPS, отправки телеметрии, пользовательских токенов и приватных ключей.**

## Установка

1. Нужен LG webOS с root-доступом, Homebrew Channel и требуемыми разрешениями LS2/ACG.
2. Установите файл com.gamefree24.byedpi_0.6.32_all.ipk через Homebrew или webOS SDK.
3. Откройте приложение, нажмите «Включить ByeDPI», проверьте статус RUNNING.
4. Запустите официальный YouTube. Проверьте картинку, звук и перемотку.
5. При проблемах отключите ByeDPI через интерфейс и используйте ранее сохранённый пакет для отката.

**IPK не устанавливает постоянный системный автозапуск.** После холодной загрузки может потребоваться перезапуск YouTube либо отдельная настройка Homebrew. Не устанавливайте без резервной копии.

## Проверка совместимости

Частная исходная версия 0.6.31 подтверждена пользователем на LG 65NANO896PC с webOS 6.6. **Эта очищенная Public 0.6.32 на реальном телевизоре пока не проверена.** В частности, LG 65UP7600LF и webOS 26 требуют отдельного теста. Не обещаем совместимость с любой прошивкой.

## Чем отличается от обычного ByeDPI

Вместо одного исполняемого файла здесь есть сервис webOS/Homebrew/LS2, управление с телевизионного пульта, автоопределение IP, локальная маршрутизация DNS/SNI с учётом изоляции Cobalt, отдельные видеомаршруты, диагностика и откат. Реальный результат зависит от провайдера, webOS и аппаратной платформы.
